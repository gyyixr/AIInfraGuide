## 本章解决什么问题

前面章节逐项解释数据、并行、状态和恢复。

本章把这些机制放进同一个设计问题：给定目标能力、数据与资源，怎样制定可运行、可恢复且可解释的训练方案。

这里的成本不只指一次step的毫秒数。

还包括达到目标质量需要的token、真实执行FLOPs、占用GPU-hours和故障恢复损失。

一个更快但需要训练更多token的方案，未必更早达到目标。

一个参数更省显存但通信暴露更多的方案，也未必更便宜。

## 四篇专题

### 15.1 参数、FLOPs与训练预算的完整推导

从GQA、SwiGLU和embedding的矩阵shape计算逻辑参数。

再从forward、dgrad和wgrad推导6PN。

补上attention pair二次项、重计算、模型状态与通信口径。

最终把FLOPs转换为训练时间与GPU-hours，明确MFU和goodput的区别。

### 15.2 五类大模型配置与并行方案设计

分别讨论70B常规长度、70B长上下文、400B Dense、1T级MoE和百万上下文。

每类先明确主要矛盾，再列候选和淘汰条件。

显存、batch、bubble、expert双网格与恢复格式一起验收。

这些候选是设计练习，不是某一硬件环境的最优配置声明。

### 15.3 训练课程、优化算法与数值稳定性

把阶段变化连接到数据、optimizer状态、schedule与精度。

完整手算clip后的AdamW更新。

解释token计数为何影响warmup，以及BF16动态范围与小更新精度为何不同。

比较Adafactor、Shampoo和Muon改变了哪些状态与运算。

### 15.4 Scaling Laws、超参数迁移与实验设计

在固定计算预算下推导参数与token的联合最优点。

用IsoFLOP曲线说明怎样设计pilot，而不是背一个固定token/parameter比。

通过简单函数更新例子解释初始化尺度和更新尺度的差别。

再讨论μP迁移条件、不确定性和真实实验记录。

## 先固定训练合同

| 项目 | 必须回答 |
|---|---|
| 目标 | 什么能力、什么质量门槛 |
| 模型 | 层数、维度、attention、expert与辅助头 |
| 数据 | 来源、tokenizer、唯一库存与重复预算 |
| 长度 | 常见长度、长尾与依赖距离 |
| 优化 | optimizer、schedule、batch与精度 |
| 平台 | GPU、互联、CPU、内存与存储 |
| 恢复 | RPO、RTO、checkpoint与数据连续性 |
| 交付 | 可复现checkpoint、日志与评测 |

缺少这些条件，模型名称与GPU数量不足以决定并行方案。

## 本章统一计数规则

矩阵乘加计2 FLOPs。

GB使用十进制，GiB使用二进制。

参数量默认逻辑参数，物理复制副本另算。

有效token默认实际参与约定训练目标的token。

执行token与padding token使用不同名称。

通信字节默认每rank单方向payload，另报其他口径时说明乘数。

## 三条特别重要的推导

第一条是状态所有权：谁持有参数、梯度、master与moments，决定显存公式。

第二条是实际工作量：线性层、attention pairs、重计算和路由分别决定FLOPs。

第三条是统计效率：相同系统速度下，需要多少工作才能达到目标质量。

三者不能用一个利用率数字替代。

## 从公式走向实测

```mermaid
flowchart LR
  A[训练合同] --> B[容量与成本下界]
  B --> C[合法候选]
  C --> D[数值基线]
  D --> E[目标shape基准]
  E --> F[真实数据与恢复canary]
  F --> G[长期质量与goodput]
```

公式用于排除明显不可行方案。

小实验用于验证数学与状态合约。

目标硬件用于校准kernel与通信。

长运行用于验证质量、恢复与真实成本。

## 学习验收

1. 独立推导一个GQA+SwiGLU模型的主要参数量。
2. 解释6PN的来源与遗漏项。
3. 区分MoE总参数与活跃参数的用途。
4. 给出同模型两套并行候选并说明取舍。
5. 手算AdamW的一次裁剪与更新。
6. 用token预算重新计算batch变化后的warmup。
7. 推导固定计算预算下的参数与数据最优关系。
8. 说明哪些结论只能由真实硬件或长程训练支持。

## 运行边界

本章Python示例用于算术、shape和更新公式检查。

没有执行70B、400B、1T或百万上下文训练。

硬件峰值、吞吐和预算数字都在正文注明假设。

最终方案必须通过目标版本、数据与拓扑的实验。
