## 1. 先建立一个不会变化的算术基准

训练 reward 没有上升，可能是算法不适合，也可能只是 mask 错了一位。直接运行大模型很难区分这两种情况。本节用少量固定数字，先确认每个环节到底在计算什么。

实验文件是 `labs/llm_rl/rl_lab.py`，语义检查是 `labs/llm_rl/test_rl_lab.py`。运行方式：

```bash
# 在 AIInfraGuide 仓库根目录执行
python3 -m unittest discover -s labs/llm_rl -p 'test_*.py' -v
python3 labs/llm_rl/rl_lab.py --steps 1
```

这里只用 Python 标准库的双精度浮点数，不使用 GPU。误差容限针对这个小实验；不能将它直接搬成 BF16 大模型的跨引擎误差门槛。

### 1.1 固定符号与约定

| 符号 | 本节含义 | 是否随 actor 更新 |
|---|---|---|
| $r_i$ | 一条回答的外部奖励 | 否 |
| $A_i$ | 同组奖励构造的优势 | 否 |
| $p_{old}$ | 采样快照对实际动作的概率 | 否 |
| $p_\theta$ | 当前 actor 对同一动作的概率 | 是 |
| $q$ | 参考策略 | 否 |
| $\rho$ | $p_\theta/p_{old}$ | 是 |

本节 PPO 先写**需要最大化**的 surrogate；训练程序取负号，将它改成最小化 loss。标准差使用总体方差，即除以组大小 $G$，不使用 $G-1$。

## 2. GRPO：四个奖励如何变成四个优势

同一 prompt 采样四次，奖励为：

$$
r=[0,0,1,1],\qquad \bar r=\frac{0+0+1+1}{4}=0.5.
$$

总体方差和标准差为：

$$
\sigma^2=\frac{4\times0.5^2}{4}=0.25,\qquad\sigma=0.5.
$$

归一化优势：

$$
A_i=\frac{r_i-\bar r}{\sigma+10^{-8}}
\approx[-1,-1,1,1].
$$

对应实现：

```python
mean = sum(rewards) / len(rewards)
std = math.sqrt(sum((r - mean) ** 2 for r in rewards) / len(rewards))
advantages = [(r - mean) / (std + 1e-8) for r in rewards]
```

实际输出为约 `±0.99999998`，不是严格的 `±1`，因为分母加了 epsilon。检查时应使用近似比较。

### 2.1 所有回答都错了怎么办

若奖励为 `[0,0,0,0]`，均值、标准差和分子全是零，优势为 `[0,0,0,0]`。全部答对 `[1,1,1,1]` 也一样。

这说明**组内没有相对学习信号**，并不说明模型已学好。必须同时看平均奖励和零方差组占比：

| reward 均值 | 零方差比例 | 可能解释 |
|---|---|---|
| 很低 | 很高 | 任务太难、答案解析失败、采样探索不足 |
| 很高 | 很高 | 任务已较容易，或奖励函数被利用 |
| 中间水平 | 较低 | 有相对信号，但仍需检查奖励是否正确 |

`group_size=1` 在本实验中直接报错。把 epsilon 调大不能凭空创造组内比较对象。

## 3. PPO：正优势和负优势要分别手算

取 $\epsilon=0.2$，允许区间为 $[0.8,1.2]$：

$$
S(\rho,A)=\min\left(\rho A,
\operatorname{clip}(\rho,0.8,1.2)A\right).
$$

| $A$ | $\rho$ | 原始项 $\rho A$ | 裁剪项 | 最终 surrogate |
|---:|---:|---:|---:|---:|
| $2$ | $1.5$ | $3$ | $2.4$ | $2.4$ |
| $2$ | $0.5$ | $1$ | $1.6$ | $1$ |
| $-2$ | $0.5$ | $-1$ | $-1.6$ | $-1.6$ |
| $-2$ | $1.5$ | $-3$ | $-2.4$ | $-3$ |

正优势意味着希望提高这个动作的概率。提高得太多时，surrogate 变平，不再额外奖励。负优势意味着希望降低概率；降低得太多时同样变平。

反方向变差时仍保留惩罚，因此不能用 `clip(ratio) * advantage` 直接替代 `min(...)`，否则表格中的第二行和第四行都会错误。

### 3.1 clip fraction 的定义也要对齐

常见指标有两种：

- 概率比落在区间外的 token 比例。
- surrogate 真正选中平坦裁剪分支的 token 比例。

两者不同。例如 $A=2,\rho=0.5$ 在区间外，但目标仍使用原始项。本实验字段 `active_clip_fraction` 使用第二种定义。与框架日志比较前，先查框架的计算式。

## 4. GAE：从最后一个 token 倒着算

取三个 token，$\gamma=1,\lambda=0.9$，终点确实终止：

$$
r=[0,0,1],\qquad V=[0.2,0.3,0.4,0].
$$

这里四个 value 对应初始状态、后续状态以及末尾状态。记 $d_t$ 为这一步是否真正终止：

$$
\delta_t=r_t+\gamma(1-d_t)V_{t+1}-V_t,
\qquad
A_t=\delta_t+\gamma\lambda(1-d_t)A_{t+1}.
$$

先算 TD error：

$$
\delta_0=0+0.3-0.2=0.1,\quad
\delta_1=0+0.4-0.3=0.1,\quad
\delta_2=1-0.4=0.6.
$$

再倒序递推：

| 步骤 | 计算 | 优势 |
|---|---|---:|
| 最后一步 | $A_2=0.6$ | $0.6$ |
| 中间一步 | $A_1=0.1+0.9\times0.6$ | $0.64$ |
| 第一步 | $A_0=0.1+0.9\times0.64$ | $0.676$ |

若用 $A+V$ 作为 value target，结果为 `[0.876, 0.94, 1.0]`。这组数值可用于查倒序索引、折扣因子、终止 mask 是否写对。

### 4.1 截断不是必然终止

设一条轨迹仅收集到一步，奖励为 0，当前 value 为 0.3，后续状态 value 为 0.8：

- 任务真正终止：$\delta=0-0.3=-0.3$。
- 收集窗口结束、任务仍可继续：$\delta=0+0.8-0.3=0.5$。

因此，把所有达到 `max_tokens` 的轨迹一律当作成功终止会改变训练目标。是否允许 bootstrap、是否将截断回答计分，必须由任务定义决定。

实验 `gae()` 每次只接收一条连续轨迹。若多条轨迹拼成一个数组，除了终止标志还必须切断不同轨迹之间的递推；本函数没有替你处理 packed sequence 的边界。

## 5. DPO：用初始损失判断 reference 是否对齐

设当前策略和参考策略对 chosen/rejected 的回答 log-prob 分别是：

$$
\ell_\theta^+=-2,\quad\ell_\theta^-=-3,
\quad\ell_{ref}^+=-2,\quad\ell_{ref}^-=-3.
$$

DPO 的 logit：

$$
z=\beta[(\ell_\theta^+-\ell_\theta^-)
-(\ell_{ref}^+-\ell_{ref}^-)]=0.
$$

所以 loss 为 $-\log\sigma(0)=\log2\approx0.693147$。

将当前策略改为 $\ell_\theta^+=-1,\ell_\theta^-=-4$，取 $\beta=0.1$，则 $z=0.2$，loss 约为 $0.598139$。chosen 相对 rejected 的概率比提升，损失下降。

实现使用稳定形式：

```python
loss = max(0.0, -z) + math.log1p(math.exp(-abs(z)))
```

这样即使 $z=-1000$ 也不会先计算 `exp(1000)` 导致溢出。这里输入是**回答 token log-prob 的求和**；若换成长度平均，已经改了所优化的目标。

## 6. Mask：不能把 padding 算进分母

给定 per-token loss `[1,3,999]`，response mask 为 `[1,1,0]`：

$$
L=\frac{1+3}{2}=2.
$$

以下两种写法都错：

```python
sum(values) / len(values)     # 把 padding 加到分子
sum(v*m for v, m in zip(values, mask)) / len(values)  # 分母仍包含 padding
```

脚本先选有效项，再归约，因此被 mask 掉的 NaN 也不进入计算。实际 GPU 张量中，`NaN * 0` 仍然是 NaN；loss 计算应避免在无效位置产生 NaN，或用合适的选择操作。空 response 在实验里明确报错，以便尽早发现数据问题。

## 7. 用有限差分验证“公式看起来对”

第 10.2 节训练脚本手写 softmax 策略梯度。为了避免手写梯度与手写解释共同犯错，测试使用独立的数值近似：

$$
\frac{\partial L}{\partial z_j}
\approx\frac{L(z_j+h)-L(z_j-h)}{2h},\qquad h=10^{-6}.
$$

固定 batch、奖励、优势、old 概率和 reference，只扰动当前 actor 的一个 logit。测试覆盖所有 16 个参数，并包含非零 KL 系数和部分裁剪分支。

不要选择恰好位于裁剪折点的参数做这个检查，因为目标在折点处没有唯一导数。也不要在两次 loss 计算之间重新抽样，那样差值混入了采样噪声。

## 8. 自测与参考答案

**问题 1：奖励都加 10，优势是否变化？** 组内减均值会消去常数，优势不变。但 reward 日志和其他未中心化的目标可能变化。

**问题 2：奖励都乘 10，优势是否完全不变？** 不带 epsilon 时不变；本实现有固定 epsilon，因此存在极小差异。若移除 std 归一化，则优势也会放大 10 倍。

**问题 3：PPO 的 ratio 初始为 1，loss 均值为 0，是否无需 backward？** 不是。优势求和为零只说明该点的函数值；不同动作的 log-prob 对参数的导数不同，因此参数梯度通常不为零。

**问题 4：本节测试通过，是否证明真实 LLM 的 log-prob 正确？** 没有。还需独立检查 causal shift、padding side、attention mask、chat template、temperature 和生成/训练后端之间的概率语义。
