## 📖 本章概述

如果我们知道同一道题的两个回答中，哪个更符合要求，是否一定要先训练奖励模型，再运行 PPO？本章沿着同一份偏好数据走两条路：一条把“更喜欢谁”拟合为一个奖励函数；另一条把这个偏好直接用于更新语言模型。

学习本章前，需要理解序列概率是 token 条件概率的乘积，以及 KL 正则如何限制策略偏离参考模型。暂时不熟悉 PPO 的 Critic，也可以独立学习 DPO。

## 📑 章节结构

### 4.1 偏好数据与奖励模型

偏好样本的基本单位是 `(prompt, chosen, rejected)`。三段文本必须共享同一问题、同一上下文和同一评价准则。把不同问题的回答配在一起，模型容易学到题目难度，无法得到有意义的条件偏好。

本节完成四件事：

1. 将人类偏好写成 Bradley–Terry 概率模型，用分数差预测胜者。
2. 手算奖励差为 0、1、2 时的胜率与损失，理解排序分数不等于准确率。
3. 追踪两条回答从 tokenization、padding、终止位置提取到一对标量的完整路径。
4. 设计按 prompt 分组切分的数据流程，识别长度偏差、标注分歧与奖励过拟合。

奖励模型输入通常为两组 `[B, L]` token，输出两组 `[B]` 分数。它是需要学习的打分器；PPO 中预测未来回报的 Value 模型是另一种角色，二者不能因为都输出标量就混为一谈。

### 4.2 DPO 推导与实践边界

从下面的 KL 正则目标出发：

$$
\max_\pi\;\mathbb E_{y\sim\pi}[r(x,y)]-\beta D_{\mathrm{KL}}(\pi\|\pi_{\mathrm{ref}}).
$$

在固定 prompt 下，最优策略与参考策略的概率比编码了奖励；把这个关系代入偏好概率，未知的归一化常数恰好相消，于是得到 DPO 的二分类损失。

本节不止给出公式，还逐项解释：

- 为什么 chosen 与 rejected 必须共享 prompt。
- 为什么参考模型应冻结，缓存的参考 logprob 要绑定模板与 token IDs。
- 为什么原始 DPO 使用回答 token 的 logprob **求和**。
- 为什么降低 pair loss 不保证每个 chosen 的绝对概率上升。
- 为什么离线 DPO 没有自动获得在线探索能力。

## 🧮 一个贯穿本章的例子

固定同一道题，参考模型认为两个候选的相对概率为 $1:1$，当前策略认为是 $3:1$。设 $\beta=0.2$，则 DPO 的分类 logit 为 $0.2\log3\approx0.2197$，对 chosen 的预测胜率约为 $0.555$。

这个数字同时说明两件事：策略已经向 chosen 移动；偏好分类仍有较大的优化空间。它并不表示 chosen 在任务上只有 55.5% 的正确率，因为这里预测的是条件偏好。

## 🛠️ 学习与实践路径

| 步骤 | 要产出的可检查结果 |
|---|---|
| 清洗十组偏好样本 | 每对问题完全一致，列出选择原因与是否平局 |
| 实现 pair loss | 分数相等时为 $\log2$，交换胜负后损失方向反转 |
| 提取回答 logprob | 人工标出 prompt、回答、EOS、padding 的 mask |
| 检查参考缓存 | 修改模板后缓存应失效，不能静默继续使用 |
| 对照离线与在线方法 | 明确采样成本、数据覆盖、奖励调用、部署组成 |

## 🎯 自测与参考答案

**问题 1：奖励模型给两条回答分别打 8 分和 6 分，能否说前者正确率是 80%？**

不能。Bradley–Terry 只由分差预测偏好概率；分数整体平移不改变偏好。正确率需要独立的、明确的正确性标签。

**问题 2：DPO 不训练独立奖励模型，是否不需要评价标准？**

仍然需要。评价标准已经体现在 chosen/rejected 标签里；含噪、偏斜或不一致的标签会直接影响策略。

**问题 3：DPO 和 PPO 能否共用相同的参考模型？**

概念上可以，但必须核对训练阶段、tokenizer、模板与权重版本。它们的损失、数据来源和对参考模型的使用方式不同。
