看到一个新算法名字时，先找它修改了哪一行：优势怎么计算、token loss 怎么归约、ratio 怎么裁剪，还是哪些样本被保留。按这四个问题拆开，才能理解方法之间的关系，也能避免把一个配置开关误当作完整论文配方。

本文以基础 outcome GRPO 为参照，不把各框架随版本变化的默认值当成算法定义。所有例子都是可手算的教学设置。

## 1. 先把基础配方拆开

一轮基础 GRPO 可以分成四个阶段：

```text
同题采样 G 次
  → 用组均值/标准差构造 advantage
  → 对每个 token 计算 clipped surrogate
  → 按回答或 token 归约并更新
```

把有效 token 的 surrogate 统一记为 $f_{i,t}$。后面讨论归约时不再重复写完整 ratio 公式，以免把不同变化混在一起。

| 方法/选择 | 优势 | 典型归约或更新变化 |
|---|---|---|
| 基础 outcome GRPO | $(R_i-\bar R)/s_R$ | 原始形式先按回答长度平均 |
| RLOO baseline | $R_i-\bar R_{-i}$ | REINFORCE 风格，具体裁剪/归约取决于实现 |
| DAPO 配方 | 组相对优势 | 非对称 clip、动态采样、token 级 loss、过长奖励处理 |
| Dr. GRPO 思路 | 去掉组标准差缩放 | 去掉逐回答长度归一化，使用固定归一化常数 |

尤其注意：RLOO 首先描述 leave-one-out baseline，不应把“用了这个 baseline”自动等同于某个框架整套 RLOO Trainer 的所有选项。

## 2. RLOO：用其他回答估计 baseline

同一个问题独立采样 $G$ 个回答，定义：

$$
\bar R_{-i}=\frac1{G-1}\sum_{j\ne i}R_j,
\qquad A_i^{\mathrm{LOO}}=R_i-\bar R_{-i}
$$

如果评分器固定，其他回答与当前回答条件独立，则该 baseline 不依赖当前采样动作，满足标准 baseline 恒等式的条件。

对照普通组中心化：

$$
A_i^{\mathrm{center}}=R_i-\frac1G\sum_j R_j
$$

展开可得：

$$
A_i^{\mathrm{LOO}}=\frac{G}{G-1}A_i^{\mathrm{center}}
$$

取奖励 $[0,0,1,1]$：

- 组中心化：$[-0.5,-0.5,0.5,0.5]$。
- RLOO：$[-2/3,-2/3,2/3,2/3]$。
- 组标准差归一化：$[-1,-1,1,1]$，这里使用总体标准差。

前两者在固定组大小时只差一个常数；第三种还包含由随机奖励决定的标准差分母。

### 2.1 为什么“包含自己”会有影响

对未裁剪的序列 REINFORCE、固定奖励与同题独立采样，有：

$$
\mathbb{E}\left[(R_i-\bar R)\nabla\log\pi(y_i)\right]
=\left(1-\frac1G\right)\nabla J
$$

原因是自身奖励以 $1/G$ 权重进入 baseline。RLOO 消除了这项缩放，恢复对应的无偏估计。

这不是说基础 GRPO 完全不能学习；它说明 baseline 构造会改变梯度尺度。加入标准差归一化、裁剪、不同长度归约后，不能再用这个简单常数描述全部差异。

[Back to Basics](https://arxiv.org/abs/2402.14740) 是理解 LLM REINFORCE 与 leave-one-out baseline 的原始研究来源。

## 3. 标准差归一化改变了问题权重

组内减均值只改变相对零点；除以标准差还会改变尺度。

假设两组评分分别为 $[0,0.02]$ 和 $[0,2]$。中心化优势分别是 $[-0.01,0.01]$ 和 $[-1,1]$；除以各自标准差后，两组都变成 $[-1,1]$。

这种尺度不变性有时是优点，但也意味着小差异甚至微小噪声可能得到与大差异相近的更新权重。

对于二元奖励，若组内成功比例为 $p\in(0,1)$，总体标准差为 $\sqrt{p(1-p)}$：

$$
A_{\mathrm{success}}=\sqrt{\frac{1-p}{p}},\qquad
A_{\mathrm{failure}}=-\sqrt{\frac{p}{1-p}}
$$

$p=1/4$ 时，成功回答优势为 $\sqrt3$，失败回答为 $-1/\sqrt3$；$p=3/4$ 时则相反。

所以 reward normalization 不只是“方便训练的除法”：它让不同成功率组中的单个正负样本获得不同权重。取消缩放后，梯度又会直接依赖原始奖励单位，学习率和奖励权重需要一起重新检查。

## 4. 三种 loss 归约，三个不同权重

设 $N$ 条回答，长度为 $T_i$，每 token loss 为 $\ell_{i,t}=-f_{i,t}$。以下暂不考虑 KL，以便看清分母。

### 4.1 按回答平均

$$
L_{\mathrm{seq}}=\frac1N\sum_i\frac1{T_i}\sum_t\ell_{i,t}
$$

每条回答总权重相同，每个 token 的权重却为 $1/(N T_i)$。短回答的单个 token 权重更大。

### 4.2 全局有效 token 平均

$$
L_{\mathrm{token}}=\frac{\sum_i\sum_t\ell_{i,t}}{\sum_i T_i}
$$

同一 batch 内每个有效 token 权重相同。长回答包含更多 token，因此对总更新的贡献更大；总分母还随采样长度变化。

### 4.3 固定常数归约

$$
L_{\mathrm{fixed}}=\frac1{N L_{\max}}\sum_i\sum_t\ell_{i,t}
$$

$L_{\max}$ 是预先固定的最大回答长度或另一明确常数，不由当前样本实际长度决定。它消除了逐回答随机长度分母；与序列求和后平均相比只差一个固定缩放。

固定分母并不保证模型不会变长。奖励设计、任务难度、终止概率和其他优化因素仍然影响长度。

### 4.4 用数字看差异

两条回答长度为 2 和 8，第一条每 token loss 为 1，第二条每 token loss 为 3，取 $L_{\max}=8$：

| 归约 | 计算 | 结果 |
|---|---|---:|
| 按回答平均 | $(2/2+24/8)/2$ | 2.0 |
| 全局 token 平均 | $(2+24)/(2+8)$ | 2.6 |
| 固定分母 | $(2+24)/(2\times8)$ | 1.625 |

这不是单纯的显示差异；梯度也会按相同权重组合。比较实验时，不能只更换 `loss_type` 而忽略实际更新尺度。

## 5. Dr. GRPO：分开处理长度与难度缩放

[Dr. GRPO 论文](https://arxiv.org/html/2503.20783v2) 分析了组标准差和回答长度归一化带来的优化偏差。理解其思路需要同时看两件事：

1. 优势使用中心化奖励，避免再除以组内标准差。
2. 移除逐回答长度分母，以固定常数缩放 token 求和。

示意目标可写为：

$$
J_{\mathrm{Dr}}=\frac1{N L_{\max}}\sum_{i,t}m_{i,t}
\min\left(\rho_{i,t}(R_i-\bar R),\operatorname{clip}(\rho_{i,t})(R_i-\bar R)\right)
$$

参考 KL 是否存在、如何归约，仍需由完整配方决定。不能因为采用固定分母就自动推出 KL 系数或采样设置。

在 [TRL 官方文档](https://huggingface.co/docs/trl/grpo_trainer) 的参数组织中，loss reduction 与 reward scaling 是独立概念。因此看到类似 `loss_type="dr_grpo"` 的设置，还应继续检查奖励缩放选项是否与要复现的配方一致；具体可用值以固定版本为准。

## 6. DAPO：四项配合，而不是一个 clip 参数

[DAPO 原论文](https://arxiv.org/html/2503.14476v2) 给出四项主要设计：非对称裁剪、动态采样、token 级损失和过长奖励处理。下面按它们解决的问题解释，不把论文的整套训练结果归因于单个开关。

### 6.1 Clip-Higher：分开设置上下界

对 ratio 使用：

$$
\operatorname{clip}(\rho,1-\epsilon_{\mathrm{low}},1+\epsilon_{\mathrm{high}})
$$

若 $\epsilon_{\mathrm{low}}=0.2,\epsilon_{\mathrm{high}}=0.28$，上界为 1.28，下界为 0.8。

对于正优势 $A=2$、ratio=1.25：对称 0.2 裁剪给出 2.4；新上界允许得到 2.5。对于负优势 $A=-2$、ratio=0.7，下界没变，仍给出 -1.6。

这能改变正向概率增长的可用范围，但并不是无条件“增加探索就更好”。仍应观察 entropy、ratio 尾部和独立评测。

### 6.2 Dynamic Sampling：用补采样填满有效组

二元奖励下，全对或全错组的任务优势都为 0。动态采样可以继续抽取新问题/回答，直到收集到足够多包含不同奖励的组，或达到明确预算上限。

例如目标是 32 个有效组，第一批 32 组中只有 20 组有信号；可以再采样补足剩余 12 组，而不是固定用 20 组悄悄改变训练 batch。

但过滤也改变了训练问题分布。必须同时记录：

- 原始尝试的问题数与生成 token 数；
- 全对、全错和其他无效组比例；
- 最终进入更新的组数；
- 达到预算上限后的处理方式。

若只报告“保留样本每秒”，容易把被丢弃的推理成本藏起来。

### 6.3 Token-level loss

DAPO 采用按有效 token 组织的归约，改变原始逐回答长度平均造成的单 token 权重差异。它与固定常数分母不是同一个公式，上文已经给出二者数值区别。

跨 microbatch 或 DP rank 的 token 数不相等时，局部均值再平均也不等于全局 token mean。正确做法必须对分子和全局分母保持一致；若 DDP 会再平均梯度，还需补偿相应尺度。

### 6.4 Overlong reward shaping

长度上限截断的回答可能只是尚未完成，并不能简单把它等同于“完整但答案错误”。过长处理需要明确区分完成、截断和验证失败。

一种便于理解的教学惩罚是：在预设软阈值 $L_0$ 前不罚，之后到硬上限 $L_{\max}$ 逐步降低奖励：

$$
r_{\mathrm{len}}=-\operatorname{clip}\left(\frac{T-L_0}{L_{\max}-L_0},0,1\right)
$$

取 $L_0=6,L_{\max}=10$，长度 5、8、10 的惩罚分别为 0、-0.5、-1。这是解释渐进长度信号的示意公式，实际复现 DAPO 应核对原论文和固定代码版本的缓存区间、系数及截断屏蔽规则。

长度奖励会改变任务目标。设置之后要同时检查正确率、平均长度和长题表现，避免只是训练出更短的错误答案。

## 7. 不要把所有稳定性问题归咎于算法

同样的公式，以下工程差异也会改变学习行为：

| 症状 | 先检查的数据 | 可能原因 |
|---|---|---|
| 第一次更新 ratio 就偏离 1 | rollout 与重算 logprob 差 | 权重不同步、温度/模板/算子不一致 |
| reward 很高但评测下降 | 原始回答和分项分数 | reward hacking、解析漏洞、数据泄漏 |
| 几乎没有非零优势 | 各组 reward 分布 | 题目难度、采样重复、分组错误 |
| 长度迅速上升 | 正确/错误回答分别的长度 | 归约偏置、奖励诱导、EOS 概率下降 |
| loss 出现 NaN | 有效 mask、std、ratio 极值 | 空批、零方差、溢出、无效 logprob |
| 增加卡数后更新更强 | 全局 token 数与梯度尺度 | 局部平均、梯度累积与 DDP 平均不一致 |

按“输入 → 分组 → 评分 → 概率 → 优势 → 归约 → 更新”的顺序定位，通常比同时更换算法、学习率和奖励更有效。

## 8. 一个有边界的调试实验

先固定少量题目与随机种子，执行以下步骤：

1. 只采样并打印每题所有回答，人工核对至少若干完整组。
2. 离线计算奖励、均值、std 和 advantage，不更新模型。
3. 用训练端重算 token logprob，比较首次 ratio 与 1 的差异。
4. 只做一个 optimizer step，记录参数变化、loss 分项和 ratio。
5. 换新随机种子重新采样，查看独立题目上的质量变化。

一次只改变一个机制，例如固定优势，仅比较三种 loss reduction。所有实验都保留 prompt、response、版本、长度和 mask；否则无法解释差异来自哪里。

玩具任务的奖励上升验证的是闭环和数学实现，不能证明真实 LLM 的推理能力或生产性能。

## 9. 自测与参考答案

**题 1：$G=4$ 时，RLOO 与普通组中心化的比例是多少？**

答：$4/3$。只适用于没有额外标准差缩放的这两个优势表达式。

**题 2：只把 clip 上界从 1.2 调成 1.28，是否就实现了完整 DAPO？**

答：不是。动态采样、token 归约与过长处理等还需要分别核对。

**题 3：短回答有 2 个 token、长回答有 8 个 token，全局 token mean 下谁的每个 token 权重更大？**

答：相同；但长回答有更多 token，所以其总权重更大。

**题 4：取消 reward std 缩放后，能否继续把奖励整体乘 100 而不改任何配置？**

答：不应假设等价。优势与梯度尺度会显著改变，需重新检查学习率、梯度裁剪和正则项相对强度。

**题 5：动态采样保留的组全是“有对有错”，能否用保留组的成功率报告全体任务质量？**

答：不能。这是经过条件筛选的分布，必须在未筛选的独立评测集上报告质量。
