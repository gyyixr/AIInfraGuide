## 8. 本地打开全部教程

从仓库根目录启动：

```bash
npm ci
npm run site:local
```

构建结束后，在浏览器打开[本地首页](http://localhost:4321/AIInfraGuide/)，从七个模块或本页进入文章。地址保留`/AIInfraGuide/`前缀；端口以终端实际输出为准。

修改Markdown时可以使用`npm run dev:local`。全文搜索使用构建生成的Pagefind索引，更新内容后需重新构建索引。

所有已发布教程由同一网站生成。论文、GitHub源码等外部链接仍会跳到对应来源；本地审计JSON和实验结果文件主要用于仓库复核。

## 9. 怎样判断自己已学会

每条路线至少保留一组固定输入、一份手算预期、一份实际输出，以及一个能暴露错误的反例。

再回答：改变了什么对象，谁拥有状态，什么时候允许消费，哪里需要同步，性能结论适用于什么条件。

可以沿[训练项目与12周路线](./模块三-分布式训练/16.2-可复现训练项目与系统设计验收.md)或[推理项目答辩](./模块四-推理优化/12.2-推理系统设计与项目答辩.md)组织长期练习。未完成的硬件层明确保留，避免把教学模拟包装成生产复现。
