## 修复的本地构建问题

原构建命令在 `public/pagefind` 已存在时重复执行 `cp -r`，会形成 `pagefind/pagefind` 并保留顶层旧索引。现在在 Astro 构建前只清理这个生成目录，再生成并复制新索引；类型检查排除生成索引与 `.local` 临时脚本。连续构建后检查两个索引目录均无嵌套，`pagefind-entry.json` 完全相同。

## 验证边界

- 数值实验是 4 个上下文、4 个动作的 CPU bandit；0.25 → 0.9885796050 是训练上下文上的精确期望奖励，不是 LLM benchmark。
- 未在本仓库运行完整 verl、ROLL、slime GPU 训练，也未验证多 GPU 性能、跨机器 checkpoint 或生产模型质量。框架相关结论是所列官方版本的源码/文档核对。
- 网站沿用原有 GitHub Pages 的 `/AIInfraGuide/` 路径；本次启动的是本地预览，没有发布到远端网站。
- 服务停止后，在仓库根目录运行 `npm run site:local` 即可重新构建并预览。修改内容后，开发模式用 `npm run dev:local`；搜索更新仍需构建。
